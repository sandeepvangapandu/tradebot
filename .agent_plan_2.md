# Phase 2-4 Implementation Plan

## Phase 2: Entry Optimization (Agents 7-9)

### Agent 7: Smart Entry Timing
**File**: `src/execution/entry_optimizer.py`
**Purpose**: Optimize exact entry price using microstructure
**Key Components**:
- EntryOptimizer class with methods: optimize_entry_price(), wait_for_pullback(), wait_for_breakout()
- Microstructure analysis: bid-ask spread, order book imbalance, volume at bid/ask
- Pullback detection: entry on retracements to EMA/vwap
- Breakout confirmation: entry on confirmed breaks with volume
- Delay execution until optimal conditions met

### Agent 8: Volatility-Adjusted Entry
**File**: Update `src/strategy/conditions.py`
**Purpose**: Adjust entry thresholds based on volatility regime
**Key Components**:
- ATR-based entry threshold adjustment
- Volatility regime detection (low, normal, high, extreme)
- Wider stops in high volatility, tighter in low
- Position size reduction in extreme volatility

### Agent 9: Correlation Filter
**File**: Update `src/risk/portfolio_manager.py`
**Purpose**: Prevent over-concentration in correlated positions
**Key Components**:
- Real-time correlation matrix calculation
- Position rejection if correlation > 0.7 with existing positions
- Sector exposure tracking
- Diversification scoring

## Phase 3: Exit Optimization (Agents 10-13)

### Agent 10: Trailing Stop with Momentum
**File**: Update `src/execution/position_manager.py`
**Purpose**: Dynamic trailing stops based on momentum
**Key Components**:
- ATR-based trailing stop with momentum multiplier
- Accelerate trailing when momentum fades
- Slow trailing when momentum strong
- Breakeven stop after 0.5R profit

### Agent 11: Time-Based Exits
**File**: Update `src/execution/position_manager.py`
**Purpose**: Smarter time-based exits
**Key Components**:
- Time-decay based exit for options (theta-based)
- Intraday time exits (no new positions after 14:30)
- Holding time limits based on strategy type
- Weekend/holiday exits for options

### Agent 12: 4-Tier Partial Profit
**File**: Update `src/execution/position_manager.py`
**Purpose**: Scale out at multiple R:R levels
**Key Components**:
- Exit 25% at 1:1 R:R
- Exit 25% at 1:2 R:R
- Exit 25% at 1:3 R:R
- Trail final 25% with wide stop
- Averaged exit price tracking

### Agent 13: Re-Entry Logic
**File**: `src/execution/reentry_manager.py`
**Purpose**: Smart re-entry after stop out
**Key Components**:
- Track stopped-out positions
- Re-entry if setup re-forms within 5 minutes
- Maximum 1 re-entry per original signal
- Reduced size on re-entry (50%)

## Phase 4: Risk Management (Agents 14-17)

### Agent 14: Kelly Criterion Sizing
**File**: Update `src/risk/position_sizer.py`
**Purpose**: Optimal position sizing using Kelly formula
**Key Components**:
- Kelly fraction calculation from historical trades
- Half-Kelly for safety
- Cap at max risk per trade
- Track Kelly estimate accuracy

### Agent 15: Dynamic Daily Loss Limit
**File**: Update `src/risk/risk_manager.py`
**Purpose**: Adaptive daily loss limits
**Key Components**:
- Base limit: 3% of capital
- Reduce to 2% after first daily loss
- Reduce to 1% after second loss
- Reset on new day or manual override

### Agent 16: Strategy Quarantine
**File**: `src/risk/strategy_quarantine.py`
**Purpose**: Auto-disable underperforming strategies
**Key Components**:
- Track 20-trade rolling performance per strategy
- Quarantine if win rate < 30% or 5 consecutive losses
- Auto-re-enable after 24 hours with reduced size
- Manual override for quarantine

### Agent 17: Correlation-Based Limits
**File**: Update `src/risk/portfolio_manager.py`
**Purpose**: Limit correlated exposure
**Key Components**:
- Max 2 positions in same sector
- Max 3 positions with correlation > 0.5
- Reduce size when correlation high
- Alert on concentration risk
