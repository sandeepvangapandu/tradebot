## Entry point + boot sequence

`src/main.py:main()` → `TradingBot().run()` → `startup()`:

1. `_setup_logging` from settings
2. `TokenManager.get_valid_token` (cache OR auto_login OR fail)
3. `init_db(settings.database_url)` (SQLite) + `TradeLogger`
4. `record_bot_run_start` → Postgres (non-fatal if missing)
5. `InstrumentManager.download_instruments(['NSE','BSE'])`
6. `RiskManager`, `CircuitBreaker`, `StrategyQuarantine`
7. `PaperBroker`, `PartialProfitManager`, `PositionManager(trade_logger=trade_log)`, `OrderTracker`, `OrderManager`
8. `BarBuilder` started; seed 1m/5m/15m bars from historical
9. `MarketDataFeed` + `PortfolioFeed` WebSocket connect
10. `StrategyEngine` load + active-strategy SetEvaluator threads spawn
11. Bloomberg modules: UniverseScanner, SectorRotation, VIXRegime, MacroOverlay, FlowRegime, news/insider scrapers
12. ConfluenceEngine, RejectionFilter, RegimeRouter, KellySizer → `strategy_engine.set_wave5_modules`
13. `BackgroundScheduler.start` → registers all daily/interval jobs (see table below)
14. Main loop: pull signals from queue, route to OrderManager, monitor health

Shutdown (`stop()`): stop engine → order manager → close-all-positions → stop feeds/bar builder → final daily summary → record_bot_run_end.
